# Estimación de Temperatura en Conductores

Script en Python para estimar la temperatura de un conductor eléctrico utilizando Regresión Lineal. 

El modelo se alimenta de un dataset (`datos_temp.csv`) y predice la temperatura del conductor basándose en la temperatura ambiente y la velocidad del viento.

## Cómo usarlo
1. Tener instalado Python.
2. Instalar las librerías necesarias: `pip install -r requirements.txt`
3. Ejecuta el script en tu terminal: `python regresion_temperatura.py`
